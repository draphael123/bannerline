# Tiny Swords — CC0 edition

Selected visual assets in this directory come from the legacy CC0 release of
**Tiny Swords** by Pixel Frog.

- Source: https://pixelfrog-assets.itch.io/tiny-swords
- Download label: `TS_old version_CC0 Licensed`
- Original release date shown by itch.io: January 3, 2024
- License: Creative Commons Zero 1.0 Universal (CC0)
- Retrieved: July 28, 2026

The current edition of Tiny Swords uses different distribution terms. Only
files from the separately provided legacy CC0 archive are included here.

Bannerline uses selected sheets for animated troops, castles, trees, fire, and
combat effects. Pixel Frog does not require attribution for the CC0 edition,
but credit is included here in appreciation of the work.
